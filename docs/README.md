# Warehouse Scanner App - Live Demo

🎉 **Live Demo:** [View on GitHub Pages](#)

## Всі екрани додатку

Це демо версія складського сканера з усіма 12 екранами.

### Як переглянути:

1. Відкрийте `index.html` для огляду всіх екранів
2. Клікніть на будь-який екран для перегляду у повному розмірі
3. Всі екрани оптимізовані під мобільні пристрої (360x740px)

### Список екранів:

1. **screen-01-badge-scan.html** - Скан бейджа з input + camera
2. **screen-01b-badge-error.html** - Помилка бейджа
3. **screen-02-pin-entry.html** - Введення PIN
4. **screen-03-invoice-scan.html** - Скан накладної з input + camera
5. **screen-04-product-scan.html** - Головний екран: сканування товарів з input + camera
6. **screen-05-success.html** - Успішний скан
7. **screen-06-error-extra.html** - Помилка: лишній товар
8. **screen-07-error-not-in-order.html** - Помилка: немає в замовленні
9. **screen-08-line-completed.html** - Рядок закрито
10. **screen-09-order-completed.html** - Замовлення зібрано
11. **screen-10-confirm-order.html** - Підтвердження замовлення
12. **screen-11-cancel-picking.html** - Відміна збірки (без PIN)
13. **screen-12-account-locked.html** - Акаунт заблоковано

## Особливості дизайну:

- ✅ Адаптовано під 360x740px (стандартний Android)
- ✅ Всі екрани влазять без прокрутки
- ✅ Input зони з кнопками камери
- ✅ Великі, читабельні шрифти
