# Детальний опис всіх екранів складського сканера

## Загальні вимоги до всіх екранів:

### Технічні параметри:
- **Цільовий розмір екрану:** 360x740px (стандартний Android)
- **Орієнтація:** Вертикальна (portrait)
- **Принцип:** Mobile-first, без скролу
- **Шрифт:** -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto', sans-serif
- **Пароль для доступу:** mobileodoo (sessionStorage)

### Кольорова палітра:
- **Зелений (успіх):** #4CAF50
- **Червоний (помилка):** #F44336
- **Помаранчевий (попередження):** #FF9800
- **Сірий (текст):** #757575
- **Чорний (основний):** #000000
- **Білий (фон):** #FFFFFF

### Загальні елементи:
- **Кнопка "← Всі екрани":** Зверху ліворуч, rgba(0,0,0,0.7), білий текст
- **Кнопка "Наступний екран →":** Знизу праворуч, rgba(0,0,0,0.7), білий текст
- **Overlay пароля:** Темний фон rgba(0,0,0,0.95), біла форма з полем вводу

- Формат: clamp(мін_розмір, відносний_розмір, макс_розмір)

## Примітки для впровадження:

1. **Всі розміри адаптивні** - використовуйте clamp() для забезпечення коректного відображення на різних екранах
2. **Без скролу** - найважливіша вимога, особливо для екрану 04
3. **Touch-friendly** - всі інтерактивні елементи мають мінімальний розмір 60px
4. **Швидкі переходи** - екрани помилок/успіху показуються тимчасово (400-800мс)
5. **Чіткий контраст** - великі шрифти та високий контраст для зручності сканування
6. **Єдиний пароль** - sessionStorage для збереження авторизації між екранами
