# Складський Сканер / Warehouse Scanner App

Мобільний додаток для збирання замовлень на складі з підтримкою сканування штрихкодів.

Mobile application for warehouse order picking with barcode scanning support.

## Особливості / Features

- 📱 Повноекранний інтерфейс для мобільних пристроїв (планшети, телефони)
- 🔐 Двофакторна авторизація (бейдж + PIN)
- 📊 Великі візуальні лічильники для зручності роботи
- ⚡ Миттєвий візуальний фідбек на всі дії
- 🎯 Простий і зрозумілий UX для складських працівників
- 🔄 Підтримка сканерів штрихкодів

## Структура екранів / Screen Flow

### 1. Авторизація / Authentication

#### 1.1 Скан бейджа / Badge Scan
- Перший крок авторизації
- Сканування штрихкоду бейджа працівника
- Обробка помилок невірного бейджа

**Демо:** Натисніть `b` для сканування бейджа

#### 1.2 Введення PIN / PIN Entry
- Другий крок авторизації
- Цифрова клавіатура для введення 4-значного PIN
- Валідація PIN коду
- Візуальний фідбек успіху/помилки

**Демо:** Використовуйте PIN `1234`

### 2. Прив'язка замовлення / Order Binding

#### 2.1 Скан накладної / Invoice Scan
- Сканування накладної (OUT/...)
- Початок роботи з замовленням
- Обробка помилок неправильної накладної

**Демо:** Натисніть `i` для сканування накладної

### 3. Робочий процес / Working Process

#### 3.1 Сканування товарів / Product Scanning (ГОЛОВНИЙ ЕКРАН)
**Найважливіший екран додатку**

Відображає:
- Номер замовлення (зверху, фіксований)
- Інструкція про поточний товар (SKU + назва)
- **Три великі лічильники:**
  - **ЗАЛИШОК** - скільки ще треба відсканувати (помаранчевий)
  - **ВЖЕ** - скільки вже відсканували (зелений)
  - **ПОТРІБНО ВСЬОГО** - загальна кількість (чорний)
- Кнопка "ВІДМІНИТИ ЗБІРКУ" внизу

Розміри лічильників: 180-200px (займають майже половину екрана)

**Демо:** Натисніть `p` для сканування товару

#### 3.2 Успішний скан / Success Feedback
- Зелений спалах екрану
- Велика галочка ✓
- Тривалість: 200-400мс
- Автоповернення до екрану сканування

#### 3.3 Помилка "Лишній товар" / Error: Extra Item
- Червоний фон
- Повідомлення: "ЦЕ ЛИШНІЙ ТОВАР"
- Іконка попередження ⚠
- Тривалість: 800мс

#### 3.4 Помилка "Немає в замовленні" / Error: Not in Order
- Червоний фон
- Повідомлення: "ЦЬОГО ТОВАРУ НЕМАЄ У ЗАМОВЛЕННІ"
- Іконка помилки ✕
- Тривалість: 800мс

#### 3.5 Рядок закрито / Line Completed
- Зелений фон
- Повідомлення: "ГОТОВО. ДАЛІ"
- Тривалість: 500мс
- Автоперехід до наступного товару

### 4. Завершення замовлення / Order Completion

#### 4.1 Замовлення зібрано / Order Completed
- Зелений заголовок "ЗАМОВЛЕННЯ ЗІБРАНО"
- Інструкція про наклеювання ТТН
- Кількість ТТН
- Кнопка підтвердження наклеювання

#### 4.2 Підтвердження замовлення / Confirm Order
- Велика зелена кнопка "ЗАТВЕРДИТИ ЦЕ ЗАМОВЛЕННЯ"
- Номер замовлення під кнопкою
- Два можливі результати:
  - **Успіх:** "НЕСИ НА УПАКУВАННЯ" (зелений екран, 2с)
  - **Помилка:** "ЗАМОВЛЕННЯ ЗМІНИЛОСЯ" (червоний екран, потрібно сканувати заново)

### 5. Додаткові екрани / Additional Screens

#### 5.1 Відміна збірки / Cancel Picking
- Заголовок: "ВІДМІНИТИ ЗБІРКУ?"
- Введення PIN для підтвердження
- Дві кнопки: "СКАСУВАТИ" та "ПІДТВЕРДИТИ"

#### 5.2 Заблокований акаунт / Account Locked
- Темно-червоний фон
- Іконка замка 🔒
- Повідомлення: "АКАУНТ ДЕАКТИВОВАНО"
- Підказка: "Зверніться до адміністратора"
- Кнопка закриття застосунку

### Типографія / Typography

```css
Заголовки / Titles: 120-200px
Лічильники / Counters: 180-200px (найбільші!)
Інструкції / Instructions: 60-80px
Підказки / Hints: 30-50px
Кнопки / Buttons: 50-60px
```

### Принципи дизайну / Design Principles

1. **Максимальна читабельність** - великі шрифти для роботи на відстані
2. **Мінімум елементів** - фокус на одній дії за раз
3. **Швидкий фідбек** - миттєва реакція на всі дії
4. **Без прокрутки** - все важливе на одному екрані
5. **Контрастні кольори** - легко розрізняти стани
6. **Великі кнопки** - мінімум 80-100px висотою

## Розробка / Development

### Тестування екранів

У режимі розробки використовуйте наступні клавіші для навігації:

- `n` - перехід до наступного екрану (для швидкого тестування)

- `w` - симуляція невірної накладної

## Інтеграція зі сканером / Scanner Integration

Для інтеграції з реальним сканером штрихкодів:

1. Сканер зазвичай емулює клавіатуру
2. Додайте обробник події `keypress` або `input`
3. Збирайте символи до Enter
4. Відправляйте зібраний штрихкод на обробку

Приклад:

```javascript
let barcode = ''

window.addEventListener('keypress', (e) => {
  if (e.key === 'Enter') {
    processBarcode(barcode)
    barcode = ''
  } else {
    barcode += e.key
  }
})
```
